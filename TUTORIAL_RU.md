# Туториал Delta 1 Flash

Delta 1 Flash — маленькая обучаемая generative-модель. Она не использует готовые ответы в чате. Ответ получается sampling-ом из обученных весов.

## Как обучается

1. Текст читается из корпуса.
2. В режиме `char` каждый символ становится токеном.
3. Из токенов делаются пары: контекст -> следующий токен.
4. Модель хранит обучаемые строки весов для контекстов.
5. `softmax` считает вероятность следующего токена.
6. `cross entropy loss` показывает ошибку.
7. `SGD` обновляет веса.

## Запуск

```bash
python3 -m delta1flash.chat
python3 -m delta1flash.train
```

`train.py` без аргументов учит бесконечно до `Ctrl+C`.

## 50 000 слов

`data/world_words.txt` содержит 50 000 обучающих слов/буквосочетаний. Это не «все слова мира» — все слова мира невозможно честно хранить здесь. Чтобы расширить словарь, собирай большие корпуса и запускай:

```bash
python3 -m delta1flash.build_words --inputs data/wiki_all_5000.jsonl --out data/world_words.txt --target 50000
```
